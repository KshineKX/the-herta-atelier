# 书房闭环与可收起工具条

候选版本：0.4.0-beta.9。作者：Kshine。

## 本轮拟安装模块

1. 本地视频播放引擎：替代旧的单图网格变形，包含预载、双播放器交接、暂停和缺素材回退。
2. 书房五段动作：原位待机 → 起身 → 离席 → 空景保持 → 返回 → 落座 → 原位待机。没有自动定时离席；由作者手动触发。
3. 可收起工具条：固定箭头，单击立即展开或悬停200ms展开；无交互四秒收起；设置和键盘焦点锁定；四个36px按钮；按聊天区域边缘定位。隐藏按钮不挡下面的内容，也不进入Tab顺序。

现有观赏/专注、静态/动态、三幅静态画像、深浅色、藏镜与个人图库保留。挂件V2已经独立安装，不把它重复算作尚待安装的新视频模块。

## 审阅

运行本地预览后打开 http://127.0.0.1:43249/ 。完整演示应在返回落座后继续真实待机。可以选择原片直接衔接或180ms短叠化。

A起身、E离席、R返回已获作者确认；2026-10-25的S落座书本连续性修订也已获作者“可以”的认可，并已替换进候选。I沿用接回待机预览中的原片。原片直切与180ms短叠化仍可对照；真实DSH中的播放、清晰度和衔接体验待试装验收。其他两个场景的旧动作不在当前五条目录里，选择它们时回到静态画像。

## 安装边界与回退

此目录是本地开发候选，未覆盖现用安装。代码安装器仍提供预检、完整性校验、配置/链接备份和失败恢复，历史回归14/14通过，新增试装/回退演练4/4通过。

runtime-data/motion是本地审阅数据，不在默认主题发布清单内。tools/trial.mjs提供只读计划、主题与五条视频的联合试装，以及退回试装前状态的入口；需要传入带SHA-256的受控五条视频包。实际执行才创建即时备份，保留profile配置、安装状态、原链接和旧视频目录；备份内自带Rollback.cmd及独立恢复脚本。回退检测到后续用户改动时拒绝覆盖；失败试装的新视频也另存。卸载恢复最初安装状态与回到beta.8是不同操作。

本机候选入口在作者整组确认前不允许安装，且核对候选与当前源码一致。试装前完全退出DSH；入口不会自动关闭或重启应用。普通发布安装包与本机开发候选分开，暂不发布这份候选。

作者整组视觉确认前不安装、不重启、不发布。原生DSH播放流畅度和跨机兼容仍待试装后验证。
