# beta.8 本地候选修复记录

此候选没有安装到现用 DSH，也没有推送或发布。视频与挂件素材独立交付，待作者确认。

## 已核实并处理

- beta.7 未提交源码已留完整独立快照与二进制补丁，包含新增文件。后续候选保存可指认的本地版本，main 和远端保持原基线。
- 深浅切换原实现每帧写入颜色变量；新实现一次写入 23 个调色属性，使用 700ms 的整页 View Transition 统一呈现。旧宿主或减少动画偏好使用即时最终态。
- 去掉点击时等待高清图片解码的串行步骤；当前场景预加载深浅两张图，并只保留两张解码引用，离开场景后才清理旧场景图层。
- 主题变化走外观更新，避免重复完整几何测量；快速连点和卸载有旧任务失效处理。
- 原报告把 700/800/1400ms 的数字冲突直接认定为必然跳变，结论过强：beta.7 末尾 CSS 已关闭组件过渡。这里根据最终生效代码处理，未照抄全部建议。
- 安装器已有受管理区段整体替换与重复安装测试。当前实机的历史文件没有该管理标记，两种主题 ID 各出现 8 次；新增只读诊断，不把未标记行当成本项目拥有的字节而擅自删除。
- 宿主已有版本和 profile 格式探测，增加明确的只读兼容状态。未知宿主不冒充已验证版本，也不采用无插件注册即无法生效的“静态免注入”方案。
- README 顶部显示现有非商业许可，不更改既定许可，不删除完整主题画像。

## 验证边界

本轮实际运行安装器／图库回归、独立重复覆盖诊断测试与构建完整性检查。浏览器记录使用 1985×1248 视口、超清图和 2307 个合成节点。原始对比记录见 transition-validation.json；如有补充隔离复测，见 transition-validation-focused.json。记录保留原始峰值，不筛掉慢帧。预览与配置校验均不替代真实 DSH 性能验收。旧版开屏文档中的历史数字未在本轮重新宣称验证。
