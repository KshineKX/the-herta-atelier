# 源码、成品与 AI 辅助制作

The Herta Atelier 是 Kshine 策划、确定美术方向并维护的 DSH 主题插件；开发过程中使用了 AI 辅助编码和部分美术生成、修整、超分，并包含已标明来源的第三方组件。不能将其描述为全部代码和素材均由 Kshine 手写或独立绘制。

## 实际交付内容

| 内容 | 文件 | 用途 |
|---|---|---|
| 前端源码 | packages/skin/src/client.js | 布局、主题色、阅读保护、设置和装饰规则；CSS 也包含在该文件中 |
| 藏镜源码 | packages/skin/src/mirror.js | 挂件、切图、导入与交互 |
| 本机后端源码 | packages/skin/lib/index.js、gallery.js、settings.js | 注册静态资源、图库接口和配置；这些 JS 是直接运行的源码，不是二进制 |
| 开屏源码 | packages/boot/entry.js、src/ | 在上游 MIT 模块基础上定制的开屏逻辑 |
| 安装工具源码 | tools/profile.mjs、manage.mjs、bootstrap.ps1 | 安装、升级、卸载、备份和状态检查 |
| 构建/发布脚本 | packages/skin/build.mjs、tools/build.mjs、release.mjs | 将源码整理为 DSH 可加载文件和 ZIP |
| 验证代码 | tests/、packages/boot/verify/ | 回归、兼容和交互验证 |
| 图形资源 | packages/skin/assets/ | SVG、字体，以及仅在个人版存在的画像 |

src 是主要修改入口，部分 lib 文件是构建生成，另一些后端 lib 文件就是直接维护的源码；不能将整个 lib 目录一概当成生成物。安装包供直接使用，源码供修改与维护。

## 提示词的作用

提示词是描述目标的输入：例如颜色、人物气质、构图和功能需求。软件源码是执行行为的具体实现。AI 根据提示词编写代码，不会使这些代码变成“没有源码”。

图片提示词、参考与生成设置也属于制作过程记录，不能代替图片、源程序、依赖和构建脚本。只给同样提示词，不能保证生成完全相同的图片或相同版本的软件。早期原始聊天和参考图不原样纳入公共仓库，避免私人资料和未核实素材混入。

## 本项目的复现边界

源码可以构建 UI、插件运行文件与中性背景 core 包；这不表示可以仅凭仓库重现三组个人画像。画像母版、第三方参考及个人媒体不包含在公共候选中。

皮肤本身在运行时执行这些 JS/CSS 并读取本机资源，不需要再调用图像生成模型，不提供或训练 AI 模型。DSH 的对话模型属于宿主自己的功能。

AI 辅助软件项目仍需检查代码、依赖、许可、测试和实际体验；测试通过不表示没有缺陷，更不等于素材权利已经核实。维护时以具体源码和验收证据为准。
