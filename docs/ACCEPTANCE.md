## 封版检查

- 冷启动与退出；深浅快速切换；三场景；长文、代码、表格、弹窗和窄窗。
- 空图库、坏图、中文文件名、视频不兼容时可进入主界面。
- 换安装位置、重复安装、升级、卸载与失败恢复；不丢图库或修改无关 provider。
- 检查 Release 清单/哈希：无本机用户名路径、账号/凭据、旧聊天材料、官方 PV、私人图库。
- 在当前机器记录启用/停用的性能基线，再决定是否稳定发布。
