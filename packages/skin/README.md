## 安装

Web profile（把 `<完整 commit>` 换成市场条目、Release 或仓库提交里的 40 位 SHA）：

```sh
dsh plugin --profile web add "github:KshineKX/the-herta-atelier#<完整 commit>&path:/packages/skin"
```

官方 Desktop：在「插件 → 添加插件」中粘贴同一个固定目标（`github:…/#<commit>&path:/packages/skin`）；需要可选开屏与完整媒体时，也可在仓库根目录运行 `install.ps1` 或 `Install.cmd` 安装完整主题包。

## 兼容范围

宿主基线：DSH `0.2.1-rc.3`（见 `host-compatibility.json`）。更早版本只保留历史测试记录，更新版本尚未完成同等实机验收，兼容性以本机实测为准。
